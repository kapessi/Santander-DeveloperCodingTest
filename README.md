# Santander-DeveloperCodingTest

Santander developer coding test developed by Emmanuel Uraga


## API usage

To execute the API you just must call the URL https://localhost:7067/api/HackerNews?n=2, where n is the number of stories to retrieve.

![image]


##  Assumptions

- I applied a random selection when retrieving the best stories to make a dynamic feeling when calling the API.
- Also, I considered the kids property to set the comments count since the documentation mentions that.


## Unit tests

Unit test are provided for the next cases:
- 1 story requested
- 2 stories requested
- 3 stories requested
- 5 stories requested
- 10 stories requested
